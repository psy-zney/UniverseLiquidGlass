# Demo brief

Audience: Zen users installing Universe Liquid Glass. Silent native browser demo, 1600×900, 24 fps.
Show all nine celestial events, real sidebar tab changes, the active-page loading state, Downloads and installation steps.
Capture only a dedicated local profile. Local sample pages contain no account or browsing history.
Each event is presented as a short chapter sampled from the native CSS animation. Event timing is edited for the demo; the installed loop is 70 seconds (sidebar) and 84 seconds (top).
