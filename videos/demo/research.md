# Sources and scope

- Theme behavior: `src/cosmic_events.py`, `src/sidebar.css`, `src/ui.css` and generated `theme/userChrome.css` in this repository.
- UI footage: Zen Browser 1.23.2b, isolated local profile, local pages in `source/`.
- Black-hole lensing is a visual simulation in SVG, not a physical ray-tracing calculation.
- All theme graphics and demo pages are local project assets; no third-party photographs, music or web footage.
