# Universe Liquid Glass

A deep black cosmic theme for Zen Browser with liquid glass tabs, irregular twinkling stars and nine passing celestial events.

![Universe Liquid Glass](https://raw.githubusercontent.com/psy-zney/UniverseLiquidGlass/main/zen-mod/preview.png)

## Features

- Comets, stars, planets, white dwarfs, black holes, neutron stars, nebulae, blue stars and galaxies.
- Local illumination, translucent tab surfaces and illustrative gravitational lensing.
- Sidebar, top-toolbar and compact-frame events behind browser controls.
- Clear active tabs, selected-tab loading motion and readable Library panels.
- Local embedded SVG assets; no external images, fonts, JavaScript or network requests at runtime.

## Usage and compatibility

Tested on **Zen 1.23.2b / Windows**. Use dark appearance and expanded vertical tabs. Native compact mode remains available. Disable conflicting full-interface CSS themes before evaluating.

This bundle's `chrome.css` styles browser chrome. The optional `userContent.css` in the main project additionally handles native option colors and standalone internal download views; it is not installed by a chrome-only Zen Mod.

Backdrops and animation use GPU resources. Black-hole lensing is a visual approximation. Browser updates can change selectors, and macOS/Linux have not been tested directly.
